SCIENCE FIRST

A fair comparison, not a diagnosis

What are we exploring?

This investigation compares performance on four types of short cognitive activities across six anonymous participants. Results describe performance on these tasks only.

These activities are educational, not clinical tests. They do not measure a person's full intelligence, personality, brain health, or emotional ability.

Keeping it fair

  • Use the same official question set and scoring rules.
  • Keep practice attempts separate from official results.
  • Consider language familiarity, fatigue, distractions, and previous practice.
  • Interpret a sample of six cautiously; do not generalize broadly.

FEATURES & TRANSPARENCY

Know what’s included

Scoring and final challenge

  • Each of the eight activities has a separate official result.
  • A randomized 40-item mixed final unlocks after all eight activity categories have completed official attempts.
  • The 1–100 overall index summarizes task performance; it is not a validated IQ or EQ score.
  • Reaction speed is based on measured response time; use consistent devices and conditions where possible.

Important research note

This is a science-fair learning prototype, not a medical or psychological test. The interface is bilingual, but the question bank is not fully translated and validated as equivalent in Arabic. Before collecting real participant data, review consent and privacy, secure the server with HTTPS, configure strong secrets, use hosted PostgreSQL, and complete browser testing.

QUICK ANSWERS

Frequently asked questions

Does it work without internet?

The browser-only activities can run locally. The server\'s first dependency installation needs internet; cloud sync requires the configured server to be running.

Will my data appear on another device?

Not in browser-only mode. Configure the backend and sign in to sync with its database. Hosted free mode uses external PostgreSQL because free app filesystems are temporary.

Can I put it online?

Yes, with a Python ASGI-capable host, HTTPS, server-side secrets, and a database. For free Render hosting, use an external PostgreSQL database because the free app filesystem is temporary. This workspace has not published the app to a live domain.

Are IQ and EQ scores real?

No. They are task-performance indicators in a custom educational demo and must not be described as standardized or clinical IQ/EQ measurements.
